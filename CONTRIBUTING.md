# Contributing

Ideas, fixes and new fish are welcome.

1. Fork and clone the repo.
2. Run `npm start` (or open `index.html`) and play your change.
3. Keep it dependency-free: vanilla JS, Canvas 2D, no build step.
4. Keep the art original and the palette in the night-city range.
5. Open a pull request with a short description and, for visual changes, a screenshot.
